
### ✅ **1. Sistema de impresión de documentos en red**

**🎯 Objetivo:** Simular una impresora que procesa documentos en el orden en que llegan.

**⚙️ Requisitos:**

* Cada trabajo de impresión tiene un nombre, número de páginas y prioridad.
* Se procesan en orden FIFO.
* Imprimir documento = eliminarlo de la cola.

**🧱 Estructura:** Cola personalizada

**📦 Clases sugeridas:**

* `PrintJob`: atributos `name`, `pages`, `priority`
* `PrintQueue`: métodos `enqueue(job)`, `dequeue()`, `show_queue()`

**🧪 Ejemplo de acción:** Encolar 3 documentos y procesarlos uno por uno.

**💡 Nivel:** Básico

### ✅ **2. Navegador con historial (Pila)**

**🎯 Objetivo:** Simular navegación web hacia atrás usando una pila.

**⚙️ Requisitos:**

* Cada página visitada se guarda en la pila.
* Opción para “volver atrás” (pop).
* Ver historial actual (desde la más reciente hacia atrás).

**🧱 Estructura:** Pila personalizada

**📦 Clases sugeridas:**

* `WebPage`: atributos `url`, `title`
* `BrowserHistory`: métodos `visit(page)`, `go_back()`, `print_history()`

**🧪 Ejemplo de acción:** Visitar 3 páginas, retroceder una y mostrar historial.

**💡 Nivel:** Básico

---

### ✅ **3. Sistema de notificaciones (Lista enlazada + Cola)**

**🎯 Objetivo:** Manejar una lista de notificaciones y mostrar las no leídas.

**⚙️ Requisitos:**

* Todas las notificaciones se guardan en lista enlazada.
* Las no leídas se agregan a una cola.
* Consultar últimas no leídas y luego marcarlas como leídas.

**🧱 Estructuras:** Lista enlazada para historial, cola para recientes

**📦 Clases sugeridas:**

* `Notification`: `message`, `timestamp`, `is_read`
* `NotificationList`, `UnreadQueue`

**🧪 Ejemplo de acción:** Agregar 5 notificaciones, consultar las últimas 3.

**💡 Nivel:** Intermedio

### ✅ **4. Inventario por lote (Pila)**

**🎯 Objetivo:** Gestionar ingreso y salida de productos con política LIFO.

**⚙️ Requisitos:**

* Productos ingresan por lote.
* Se despacha el último ingresado.
* Consultar stock actual.

**🧱 Estructura:** Pila personalizada

**📦 Clases sugeridas:**

* `Product`: `name`, `batch`, `date`
* `InventoryStack`: `add_product()`, `remove_product()`, `view_stock()`

**🧪 Ejemplo de acción:** Ingresar 3 lotes de arroz, despachar uno, mostrar pila.

**💡 Nivel:** Básico

### ✅ **5. Soporte técnico (Cola + Lista enlazada)**

**🎯 Objetivo:** Registrar usuarios y sus tickets, atender en orden de llegada.

* Cola para orden de atención.

**📦 Clases sugeridas:**

* `User`, `Ticket`, `SupportQueue`, `TicketList`

**🧪 Ejemplo de acción:** 2 usuarios con 2 tickets, atender al primero y cerrar uno.

**💡 Nivel:** Intermedio

### ✅ **7. Evaluador de expresiones RPN (Pila)**

**🎯 Objetivo:** Evaluar expresiones matemáticas postfijas.

**⚙️ Requisitos:**

* Recibir lista de tokens (ej: `["3", "4", "+", "2", "*"]`)
* Evaluar usando pila (operadores binarios)
* Mostrar resultado

**🧱 Estructura:** Pila

**📦 Clases sugeridas:**

* `ExpressionEvaluator`: `evaluate(tokens: list)`

**🧪 Ejemplo de acción:** `"5 1 2 + 4 * + 3 -"` ⇒ Resultado: `14`

**💡 Nivel:** Medio-avanzado
